# Shahaneh Admin Dashboard

پنل مدیریتی اختصاصی فروشگاه شاهانه (Shahaneh) — رابط فارسی و راست‌چین، با تمرکز بر فروشگاه پوشاک و کفش کودک.

## طراحی و نمونه اولیه

- رابط دسکتاپ و موبایل در Figma: https://www.figma.com/design/yQriV58JX4uzOCkb5BGauL
- فایل اجرای اولیه: `index.html`
- زبان رابط: فارسی (RTL)
- هویت بصری: فیروزه‌ای شاهانه، سرمه‌ای عمیق، پس‌زمینه روشن، کارت‌های نرم و تایپوگرافی فارسی.

## مسیر توسعه

### مرحله ۱ — رابط کاربری
- [x] داشبورد دسکتاپ
- [x] طرح واکنش‌گرای موبایل
- [x] کارت‌های شاخص فروش، سفارش، مشتری و میانگین سبد خرید
- [x] نمودار فروش و خلاصه وضعیت سفارش‌ها
- [x] جدول آخرین سفارش‌ها و دسترسی‌های سریع
- [ ] تکمیل صفحات داخلی و حالت تاریک
- [ ] دسترس‌پذیری، حالت‌های خالی/خطا/بارگذاری و جست‌وجوی سراسری

### مرحله ۲ — اتصال داده واقعی
- اتصال امن به WordPress و WooCommerce از طریق REST API و کلیدهای محدود دسترسی
- نمایش سفارش‌ها، جزئیات سفارش، مشتریان، محصولات، تنوع‌ها، موجودی و دسته‌بندی‌ها
- ویرایش قیمت و موجودی با تأیید کاربر و ثبت تاریخچه تغییرات
- گزارش درآمد، سود (در صورت وجود داده بهای تمام‌شده)، نرخ تبدیل و محصولات پرفروش
- همگام‌سازی و مدیریت خطاهای API

### مرحله ۳ — عملیات فروشگاه
- مدیریت ارسال، وضعیت سفارش و مرجوعی
- کوپن‌ها و کمپین‌های تخفیف
- هشدار کمبود موجودی و سفارش‌های نیازمند پیگیری
- خروجی CSV و گزارش‌های بازه‌ای
- نقش‌ها و سطح دسترسی مدیر، اپراتور و انبار

### مرحله ۴ — بازاریابی و رشد
- اتصال Metricool برای تقویم محتوا و تحلیل شبکه‌های اجتماعی، در صورت فعال بودن دسترسی
- اتصال OpenSEO برای پایش کلمات کلیدی و وضعیت سئو
- استفاده از Canva برای طراحی بنرها و محتوای شبکه‌های اجتماعی
- مرکز اعلان‌ها و گزارش عملکرد کمپین‌ها

## معماری پیشنهادی

- Frontend: رابط واکنش‌گرای ماژولار؛ هر بخش صفحه و مسیر مستقل داشته باشد.
- Backend: سرویس امن واسط برای WooCommerce؛ کلیدهای API هرگز در مرورگر یا مخزن عمومی قرار نگیرند.
- Data: دریافت صفحه‌بندی‌شده، کش کنترل‌شده و همگام‌سازی وب‌هوک‌ها.
- Security: نقش‌محور، ثبت رویدادهای حساس، اعتبارسنجی ورودی و تأیید عملیات مالی.
- Deployment: پس از آماده شدن backend و متغیرهای محیطی، استقرار روی سرویس میزبانی مناسب.

## نکته مهم

مقادیر فعلی داشبورد نمونه نمایشی هستند و هنوز داده زنده فروشگاه نیستند. اتصال واقعی به سایت فقط پس از تنظیم دسترسی امن WordPress/WooCommerce و تست در محیط امن انجام می‌شود. هیچ کلید محرمانه یا رمز عبوری نباید در این مخزن ثبت شود.
