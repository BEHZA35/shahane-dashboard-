# Shahaneh Admin Dashboard

پنل مدیریتی اختصاصی فروشگاه شاهانه (Shahaneh) — رابط فارسی و راست‌چین، با تمرکز بر فروشگاه پوشاک و کفش کودک.

## طراحی و نمونه اولیه

- رابط دسکتاپ و موبایل در Figma: https://www.figma.com/design/yQriV58JX4uzOCkb5BGauL
- فایل اجرای اولیه: `index.html`
- زبان رابط: فارسی (RTL)
- هویت بصری: فیروزه‌ای شاهانه، سرمه‌ای عمیق، پس‌زمینه روشن، کارت‌های نرم و تایپوگرافی فارسی.

## معماری پیشنهادی

- Frontend: رابط واکنش‌گرای ماژولار؛ هر بخش صفحه و مسیر مستقل داشته باشد.
- Backend: سرویس امن واسط برای WooCommerce؛ کلیدهای API هرگز در مرورگر یا مخزن عمومی قرار نگیرند.
- Data: دریافت صفحه‌بندی‌شده، کش کنترل‌شده و همگام‌سازی وب‌هوک‌ها.
- Security: نقش‌محور، ثبت رویدادهای حساس، اعتبارسنجی ورودی و تأیید عملیات مالی.
- Deployment: پس از آماده شدن backend و متغیرهای محیطی، استقرار روی سرویس میزبانی مناسب.

## نکته مهم

مقادیر فعلی داشبورد نمونه نمایشی هستند و هنوز داده زنده فروشگاه نیستند. اتصال واقعی به سایت فقط پس از تنظیم دسترسی امن WordPress/WooCommerce و تست در محیط امن انجام می‌شود. هیچ کلید محرمانه یا رمز عبوری نباید در این مخزن ثبت شود.


## وضعیت اجرایی فعلی

- رابط ماژولار اولیه برای داشبورد، محصولات، سفارش‌ها، مشتریان، انبار، حسابداری، بازاریابی، سئو و تنظیمات اضافه شده است.
- فایل `admin.js` فقط داده‌های نمایشی را نشان می‌دهد و برچسب پیش‌نمایش دارد.
- `server.js` اسکلت بک‌اند Node/Express را با مسیرهای فقط‌خواندنی WooCommerce آماده می‌کند.
- مسیرهای API با `ADMIN_API_TOKEN` محافظت شده‌اند؛ کلیدهای WooCommerce فقط روی سرور قرار می‌گیرند.
- فایل `render.yaml` برای استقرار Render آماده است، اما سرویس هنوز مستقر نشده و متغیرهای محرمانه هنوز تنظیم نشده‌اند.

## گام‌های لازم برای فعال شدن داده زنده

1. در WooCommerce > Settings > Advanced > REST API یک کلید جداگانه با مجوز **Read** بسازید.
2. در Render متغیرهای `WOOCOMMERCE_CONSUMER_KEY`، `WOOCOMMERCE_CONSUMER_SECRET` و یک `ADMIN_API_TOKEN` تصادفی و قوی را در Environment تنظیم کنید.
3. پس از استقرار، ابتدا `/api/health` و سپس endpointهای خواندن محصولات، سفارش‌ها و مشتریان آزمایش شوند.
4. قبل از نمایش داده واقعی در مرورگر، ورود مدیر و نشست امن (session) باید اضافه و اتصال رابط کاربری به backend تکمیل شود.

**امنیت:** کلیدها را در چت، فایل‌های GitHub، کد مرورگر یا اسکرین‌شات قرار ندهید. کلید Read-only برای مرحله اول کافی است.
